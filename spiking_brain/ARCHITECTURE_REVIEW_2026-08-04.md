## 0. 検証の要旨 (先に結論)

1. **設計ドキュメント (CONTEXT.md 5/22) と現実が乖離している。** roster の status 欄
   (M0=未実装、M1=開発中、M2=未着手) は古い。実際は M0/M0.5/M1 稼働、M2 は実装済だが collapse。

2. **最大の構造的発見: 階層 SNN は「感覚フロントエンドだけでなく、あらゆる階層境界に
   リレー核 (時間構造処理段) を要する」。** 元 roster の clean cortical stack
   (M0→M1→M2→M3) は誤りで、生物の聴覚経路 (蝸牛→蝸牛神経核→上オリーブ→下丘→MGB→A1→A2)
   の通り、境界ごとにリレー核を挟む必要がある。これは実証で二度確認された:
   - M0→M1 直結 → デフォルトアトラクタ collapse。**M0.5 蝸牛神経核の挿入で解決** (成功)。
   - M1→M2 直結 → M2 collapse。**M1.5 皮質間オンセット検出器が未挿入** (未解決)。

3. **M2 の「長時定数」は名目のみ。** `for_m2()` は M1 と causal_window (320 vs 160) しか
   違わず、軸索遅延幅・conductance 減衰・vitality 減衰は M1 と完全同一。期待機能
   (音節スケールの不変表現) が物理時定数として実装されていない。

4. **評価指標を格上げすべき。** selectivity (= within − between) は between 改善を罰するため
   不適。per-pair between (音素間 cosine 平均) を主指標に。既に 5/31 で確認済。

## 1. 中心的発見: リレー核原理

### 1.1 意図された構成 (CONTEXT.md §3) — clean cortical stack

```
[M0 蝸牛] → [M1 A1] → [M2 A2] → [M3 カテゴリ] → ...
```

境界にリレー段は無い。roster は M0-M11 の 12 モジュールで、皮質野を直列に積む。

### 1.2 生物の実際 — 各段にリレー核

```
蝸牛 → 蝸牛神経核 → 上オリーブ核 → 下丘 → MGB(視床) → A1 → A2
 M0     [R:欠落]      [R:欠落]    [R:欠落] [R:欠落]  M1   M2
```

`M0_5_COCHLEAR_NUCLEUS_DESIGN.md` §1.3 が既にこのギャップを指摘し、蝸牛神経核を
**【欠落】← 信号分解ステージ**と明示していた。

### 1.3 実証 — 境界ごとに同型の collapse が起きる

| 境界 | 直結時の症状 | 診断された原因 | リレー段 | 結果 |
|---|---|---|---|---|
| M0→M1 | per-pair between ≈ 0.956–1.000 (入力非依存デフォルトアトラクタ) | 蝸牛出力が「密な包絡 rate」で時間構造 (onset) 欠落 | **M0.5 蝸牛神経核** (Octopus/Bushy/Stellate 84ch) | ✅ per-pair 1.0→0.765、sel 0.389→0.581 |
| M1→M2 | M2 within 1.000 / between 0.74 / active 5/20 (固定点ロック) | M1 の 40ch 密スパイク列を、時間分解せず直接 M2 へ渡している (M0 生蝸牛と同じ「密入力」問題) | **M1.5 皮質間オンセット検出器** (未実装) | ⬜ 未解決 |

**原理の言明**: 各階層境界は、上流が吐く「密な rate 列」を
onset / 精密タイミング / スペクトル包絡の並列ストリームへ**再分解するリレー段**を要する。
これが無いと下流モジュールは入力非依存のデフォルトアトラクタに落ちる。
散逸構造の平衡点は「入力統計 × 時間構造 × 可塑性時定数」で決まり、時間構造が欠けると
分化が立ち上がらない。

**重要な補正 (2026-08-04、M1.5 実験後)**: この原理は M0→M1 では成立したが、**M1→M2 では
そのままでは成立しない**。M1.5 を入力再符号化リレー (遅延/同時性/両者) として 4 通り実装・
検証した結果、いずれも M2 collapse を解けなかった (`M1_5_CORTICAL_RELAY_DESIGN.md` §6.6)。
M0→M1 の collapse は**入力構造**の問題だったが、M1→M2 の collapse は**M2 自身の力学**
(訓練で 5/20 勝者総取りへ収束) の問題であり、境界ごとに必要な処置は一様ではない。
M1→M2 は「入力再符号化」でなく「M2 力学の是正」または「M1.5 を持続 drive 生成器化」が要る。

## 2. セクション別検証

凡例: ✅ 期待機能を満たす / ⚠️ 部分的 / ❌ 未達 / ⬜ 未実装

### M0 蝸牛 (Cochlea) — ✅

- **役割**: 単耳の音波形 → 時間構造をもつスパイク列への決定論的変換 (固定・学習なし)。
- **期待機能**: 音素を分化 (between 低)、時間構造保持、ホワイトノイズで自律振動しない。
- **実装**: `cochlea.rs`。40 帯域 (ERB スケール 50Hz–4kHz)、2 次 IIR biquad (Q1.15)、
  半波整流 + leaky integrator、isqrt 圧縮、閾値発火。低 8ch で phase locking。
- **実証** (本日再測定): 音素間 between = 0.268 (< 0.5 → 分化良好)。
  周波数プロファイルは音素固有 (pa=ch19, ki=ch9, tu=ch10, se=ch14, mo=ch7/8/14)。
- **判定**: ✅ 期待機能を満たす。「M0 は音素を分化している」は成立。
- **ギャップ**:
  1. ki(ch9)/tu(ch10) は**隣接帯域**にピーク → place コード上で近接し下流で潰れやすい
     (§ki-tu ボトルネックの上流要因)。
  2. 解像度 60/80 帯域の収益逓減ライン未検証。
  3. 両耳 (ITD/ILD) は範囲外 (将来 上オリーブ/MSO)。**M0.5 ラベルが蝸牛神経核と衝突**
     (M0 doc は M0.5=SOC/両耳統合、M0.5 doc は M0.5=蝸牛神経核) — 要整理。

### M0.5 蝸牛神経核 (Cochlear Nucleus) — ✅ リレー核 #1 / 本プロジェクト最大の成功

- **役割**: M0 と M1 の間の欠落していた信号分解段。音を時間/周波数/オンセットの
  3 並列ストリームに分解。**元の 12 モジュール roster には無い**、診断駆動の挿入。
- **期待機能**: per-pair between を 1.0 から下げ M1 をデフォルトアトラクタから蹴り出す。
- **実装**: `cochlear_nucleus.rs`。Octopus 4 (同時性閾値 [3,5,8,12]) +
  Bushy 40 (帯域別 phase-lock 保存) + Stellate 40 (±1 帯域プールの chopper) = **84ch**。
  専用軽量セル (ThermoNeuron ではない)。
- **実証**: sel 0.389→0.581、per-pair 1.0→0.765〜0.816、active 12/40→18-20/40。
  リレー核原理の直接実証。
- **判定**: ✅ 最大の成功。リレー段の挿入がアトラクタ脱出を生む、を実証。
- **ギャップ**:
  1. **Octopus の onset 時間分解能が粗い**。本日再測定で ki は締まった 2 波
     (`c0,c1,c2@12` / `c0,c1,c3@14`、同時性 3,3,2,1)、tu は分散 (`@13→18`、同時性 2,1,1,1)
     と onset 構造は実際に違うのに、10ms bin の fingerprint では ki-tu cosine = 0.946 に潰れる。
     → onset の締まり具合 (coincidence tightness) を保持する時間分解能が課題。
  2. 専用セル vs ThermoNeuron の哲学的統一 (設計 §5 未決)。

### M1 一次聴覚野 (A1) — ⚠️ おおむね機能、識別性が頭打ち

- **役割**: 入力スパイクパターン → 出力フィンガープリントの連続・再現的写像 F。
- **期待機能 (5 性質)**: ①決定論性 ②連続性 ③識別性 ④安定性 ⑤容量。
  不変性・カテゴリ・意味・報酬は責務外 (M2+/M3+/M5+)。
- **実装**: `ThermoNetwork::for_m1_cn_40`。grid 20×26 = 520 neurons、22,740 シナプス、
  input 84 / output 40。熱力学的ニューロン (available_enthalpy / local_entropy)、
  STDP、vitality、熱勾配軸索成長。causal_window 160 (80ms)。
- **実証**: 固定パターン sel 0.728 (M1 単体は健全)。音素 per-pair 0.765 (最良 R4)。
  ki-tu 0.966→0.883 (初の <0.9)。vitality 完全保存で各音素が独自経路。
- **判定**: ⚠️ 決定論性・連続性は満たす。識別性は ki-tu で頭打ち。④安定性・⑤容量は未定量。
- **ギャップ**:
  1. **蝸牛が開いた分化を M1 が再収束させる** (attractor)。蝸牛 ki-se 0.355 → M1 0.908。
     隣接帯域 place (ch9 vs ch10) を M1 の空間プーリングが潰す、が有力仮説。
  2. ki-tu 完全分離は M1 単独では困難 (M1.5/M2 課題)。
  3. 5 性質のうち「容量」「安定性」の定量評価が未実施。

### M1.5 皮質中継 (時相変換) — ⬜ 未実装 / 最優先設計対象

- **役割**: M1→M2 の欠落リレー核。皮質間オンセット検出器。時相変換。
  「蝸牛神経核を M1 出力に適用する」形が有力。
- **期待機能**: M1 の 40ch 密スパイク列を時間構造に再分解し M2 collapse を解消。
  長時定数で ki-tu (両 Plosive) を分離。
- **実装**: 無 (設計提案のみ。設計文書も未作成)。
- **実証**: 無。ただし M2 collapse が「必要性」を逆説的に実証。
- **判定**: ⬜ 未実装。**ki-tu ボトルネックと M2 collapse の共通解**であり最優先。
- **ギャップ**: 3 細胞型 (Octopus/Bushy/Stellate) の「M1 出力版」をどう定義するか未決。
  M1 出力は既にスパース (18-20/40) なので、蝸牛神経核とは入力統計が異なる点に注意。

### M2 二次聴覚野 (A2) — ❌ 未達 (collapse)

- **役割**: M1 の連続写像から**不変表現 (話者/ピッチ/速度不変)** を獲得。
- **期待機能**: within↑ between↓ 連続性↑、カテゴリらしいクラスタが自己組織的に創発。
- **実装**: `ThermoNetwork::for_m2` (input 40 / output 20、grid 20×22)。
  **M1 との違いは causal_window (320=160ms vs M1 160=80ms) のみ**。
  delay_range (2,40)・conductance_decay (1000)・vitality_decay (10000) は M1 と完全同一。
- **実証**: 改良 M1 (sel 0.516) 上でも M2 sel 0.236 / within 0.986 / between 0.750 /
  active 5/20。trial 1000 以降 完全停止 (固定点ロック)。5 ニューロンが全音素にロック。
- **判定**: ❌ 期待機能未達。不変性以前に音素の区別ができず退化アトラクタへ collapse。
- **ギャップ** (二重の欠落):
  1. **M1→M2 間にリレー段 (M1.5) が無い** — 密入力問題の再発 (§1.3)。
  2. **「長時定数」が名目のみ** — causal_window だけ延長し、実際の dynamics 時定数
     (delay/decay/vitality) は M1 のコピー。真の長時定数化 (音節スケール) が未実装。
  → M1.5 の挿入と M2 の真の時定数化の**両方**が要る。

### M3–M11 — ⬜ 未着手 (roster のみ)

- M3 カテゴリ / M4 海馬 / M5 報酬系 (タイプ2境界) / M6-M7 運動 / M8 視床 (gating) /
  M9 NA (覚醒) / M10 ACh (注意) / M11 小脳。
- 全て未実装。**M2 が通らない限り着手不可** (感覚経路 M0-M2 の確立が前提)。
- 現段階はタイプ1 感覚経路の確立フェーズであり、制御系 (M8-M10) とタイプ2 (M5+) は先送りで妥当。

### 並行フォークの位置づけ

- **Phase 2 DRAM**: 物理モデル + 参照ランプ ADC 検証済。HW 実装 (graded spike) への橋渡しとして並存。

## 3. フレームワーク (熱力学 + 6 原理) の検証

- **熱力学的描像 (§11)**: 散逸構造の形成が実証されている。vitality 完全保存 (decay 30) で
  「各音素が独自経路を保持」= 経路が共鳴して安定化する定常状態 (Prigogine) に整合。
  軸索成長 (熱勾配、冷たい隣接へ) も稼働。**フレームワークは有効**。

  - M0.5 の 3 細胞型は専用セルで ThermoNeuron 統一を外れている (哲学 vs 実用のトレードオフ、未決)。
  - **評価指標**: selectivity 単独は between 改善を罰する → per-pair を主指標に格上げ済 (5/31)。
