## 絶対に守るべき 6 原理

1. **局所性**: 各要素は接続された相手としか情報交換しない
2. **物理性**: 判断機構ではなく物理プロセスで構成
3. **決定論性**: 確率や乱数を使わない (初期化時を除く)
4. **整数演算**: 浮動小数点を使わない
5. **創発性**: トップダウン設計せず、局所機構から振る舞いを立ち上げる
6. **平衡としての学習**: 学習用の特別な関数を持たない、物理プロセスの結果として学習が起きる

---

## 絶対にやってはいけないこと

1. **M1 にタイプ 2 学習機能を入れない**
   - target 指定、外部報酬、正解判定は M1 の責務外 (M5 以降の責務)

2. **判断機構を入れない**
   - target_rate との比較、累積閾値判定、確率的伝送など

3. **損失関数・目的関数を使わない**
   - 学習は動的平衡として自然に起こす

4. **連続値・浮動小数を避ける**
   - DRP 実装との整合性のため

5. **LLM 的発想に逃げない**
   - 勾配降下や Attention に頼らない

6. **Phase 1 のコードを上書きしない**
   - src_phase2 に新規作成

## 学習の二分類 (重要)

- **タイプ 1 (自己学習)**: 環境との物理的相互作用による動的平衡 → M0, M1, M2, M3 など
- **タイプ 2 (教示学習)**: 人類の文明的標準を獲得 → M5 以降

両者の機構は同じ (ヘブ則、STDP)。違うのは入力構造のみ。
M1 はタイプ 1 のみ扱う。タイプ 2 は将来の上位モジュールで実装。

## 熱力学的描像 (Phase 2 の基盤)

各要素を熱力学量で記述:

| 現象 | 熱力学的解釈 |
|---|---|
| ニューロン発火 | エンタルピー消費 + エントロピー (熱) 生成 |
| 慣化 | 局所エントロピー蓄積による閾値上昇 |
| エントロピー散逸 | 熱の自然減衰 (放熱) |
| シナプス強化 (LTP) | 経路の熱伝導度上昇 |
| シナプス弱化 (LTD) | 熱伝導度低下 |
| 軸索成長 | 熱勾配に沿った経路形成 (冷たい方へ伸びる) |
| 学習 | 散逸構造の形成 (Prigogine) |

詳細は DESIGN_PHILOSOPHY.md §11 と PHASE2_INSTRUCTION.md。

## DRP マッピング (最終目標)

- ニューロン = PE (スイッチ要素)
- シナプス = 配線
- スパイク = 1 ビット信号
- 学習 = DRP の動的再構成

「学習」と「DRP の再構成」が物理的に同一視できる、これがプロジェクトの核心アイデア。
