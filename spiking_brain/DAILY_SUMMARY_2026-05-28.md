## 本日の最大成果: 音素学習の前進 (sel 0.389 → 0.537)

### 診断の連鎖

```
M2 が効かない (A案 集約も B案 内部収束も sel ≈ 0.26)
  → M1 自体が音素を分化していない (phoneme between 0.600)
    → M1 単体 + 固定パターンなら sel 0.728 (M1 は健全)
      → M0 蝸牛も音素を分化 (between 0.30)
        → per-pair: M1 平均出力が全音素ペアで between ≈ 1.0
          = M1 は入力非依存の「デフォルトアトラクタ」 に収束
```

### 解決した 2 つの介入

**介入 1: 蝸牛神経核 (M0.5) の追加** (`src_phase2_f/cochlear_nucleus.rs`)
- 生物の蝸牛神経核 = 欠落していた信号分解ステージ
- 3 細胞型を ThermoNeuron で実装:
  - Octopus (4): 広帯域オンセット検出
  - Bushy (20): 周波数別 忠実中継 + 立ち上がり強調 (entropy 適応が notch を生む)
  - Stellate (20): スペクトル包絡 rate (隣接プール)
- 20ch → 44ch に分解、 PRE between 0.225 → 0.113 (入力が分化可能に)

**介入 2: 時間スケール整合 (両輪)** ← ユーザー洞察「音素学習は本来 長時間」
- (a) 入力を速める: 音素を時間圧縮 (speed=3 で 200ms→67ms)、 STDP 窓 (80ms) 内に収納 + 反復 tile
- (b) ネットワークを遅くする: conductance/vitality 減衰を decay_slow=30 倍遅延

### 結果 (最適構成: M0.5 + speed=3 + decay_slow=30)

| 指標 | baseline | 最適構成 (10K) |
|---|---|---|
| POST sel | 0.389 | **0.537** (+38%) |
| within | 0.989 | 0.884 (飽和回避) |
| between | 0.600 | 0.347 |
| active | 12/40 | **19/40** |
| mo 応答 | 0/40 | 16/40 |
| 刈り取り | ~17,000 | **0** |

### 決定的機構

**刈り取り 0 が鍵**。 decay_slow=30 で vitality 減衰 300,000 step (150s) → 5K/10K 訓練でも vitality 維持 → **音素固有経路が保存され固定コアへの collapse を回避**。

→ **真因 = 過剰刈り取り (vitality 減衰) が音素固有経路を破壊していた**。 標準減衰 (5s) は提示間隔 (1.5s) に対し速すぎ、 各音素特異的な (提示頻度の低い) 経路を刈っていた。 ユーザーの「時間スケール不整合」 仮説の物理的実体。

(過去 S3 知見「減衰遅延は平衡点を変えない」 は単一要因。 3 要因 [蝸牛神経核 + 時間圧縮 + 遅い減衰] 揃うと平衡点が変わる。)

物理シミュレーション (`src_phase2_dram/bitline_physics.rs`) で忠実検証:
- **素朴版 (データセル和)**: 電荷共有が平均化 → 不成立 (単調性違反)
- **修正版 (参照ランプ ADC)**: 単一膜セルを参照セル群ランプと比較、 flip 本数 = 多値符号
  - 11 段階 (3.5bit)、 単調・線形 ✓
  - V_hi を Vref に近づけるほど高分解能
  - → **二値 SA のまま膜電位アナログ値が読める = §9-a (Vth/アナログ読み出しの壁) 突破**
