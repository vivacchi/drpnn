# Claude Code への次の指示: M1 プロトタイプ完成へ

これまでの実験で以下が確定しました。これに基づいて M1 を仕上げてください。

---

## 確定事項

### 1. 採用する方針: 選択肢 X (パターン再設計)

理由:
- ニューロン数増加は逆効果 (実験で確認済み)
- 訓練時間増加は天井を破れない (1k → 10k で実測)
- C と E の支配構造が selectivity 天井 0.32 の原因
- 全パターン同一時間スパンにすれば構造的に支配構造を防げる

### 2. 新パターン仕様

すべて 0-95ms、5ms step (20 入力ニューロン)。時間順序だけ変える:

- **A**: ascending (neuron 0,1,2,...,19 の順)
- **B**: descending (19,18,17,...,0)
- **C**: even-then-odd interleave (0,2,4,...,18, 1,3,5,...,19)
- **D**: phase shift (前半 10 個を 0-45ms, 後半 10 個を 50-95ms にシフト) または別の時間順序
- **E**: 固定ランダム順序

### 3. 旧 D の扱い

旧 D (190ms スパン) は削除せずに**参照ケース**として保持。完成判定には使わない。
理由: 「M1 の時間スケール上限 ~100ms」を示す重要なデータポイント。生物学的には A1 の責務範囲 (音素レベル 30-100ms) と一致しており、欠陥ではなく仕様。

仕様書には以下のように記載:
- 主動作スケール: 30-100ms (音素レベル)
- 時間分解能上限: ~100ms (causal_window 80ms 制約)
- 責務外: 単語・フレーズ (M2 責務)、楽音メロディ (M2-M3 責務)

### 4. 追加診断項目

X 採用後の評価時に、selectivity 数値だけでなく以下も同時計測:

- **パターン応答強度の対称性**: 各パターンの total spike count、極端な偏りがないか
- **各 output ニューロンの「最大反応パターン」分類**: 理想は各パターンに 8 個前後 (40/5) の専属
- **全シナプスの cumulative_sign 最終分布ヒストグラム**: 「中程度に正の中数」になっているか

これらが見えれば、selectivity が改善しなくても次の手が判断できます。

### 5. 結果判定基準 (重要: 先に固定)

X の結果を見たときの判断を、結果が出る前に確定させておく:

| selectivity 範囲 | 判定 | 次のアクション |
|---|---|---|
| > 0.55 | 大成功 | 完成判定 (基準 1-4) へ |
| 0.40 - 0.55 | 方向正しい | 機構 C (ホモシナプティック競合) を追加検討 |
| 0.32 - 0.40 | X 単独では不十分 | パラメータ調整 (Z) や M2 設計検討へ |
| < 0.32 | 改善なし | X 採用前に戻す、設計根本見直し |

**重要**: この基準に従って判断する。selectivity 0.40 を見て「あと一押しで 0.45 行けそう」とパラメータをいじるのは禁止。判定→対応の順序を守る。

### 6. 実行設定

- 訓練試行数: 1000 (10k は不要、1k で収束することを実測済み)
- 評価: 各パターン 20 試行、Phase 1 (訓練前) / Phase 3 (訓練後) / Phase 4 (持続性確認、追加 200 試行)
- ネットワーク規模: 現状のまま (cortex 400)、まずは規模を変えずに X の効果だけを測る

### 7. 報告タイミング

以下のタイミングでユーザー確認:
- X 実装完了後、初回実行結果が出たとき
- 5 表 (selectivity + 追加診断 3 つ + 持続性) を提示
- 判定基準 §5 に従って次のアクションを明示

---

## やってはいけないこと (再掲)

1. **複数の変更を同時に入れない**: X だけを変える。パラメータ調整 (Z) や機構 C は別途。
2. **「あと一押し」モードに入らない**: §5 の判定基準に従う。
3. **新パターン以外で評価を増やさない**: 評価対象パターンを途中で増やすと比較ができない。
4. **D を救おうとしない**: D は時間スケール参照ケース、救済の必要なし。
5. **M5 機能を再導入しない**: target 指定、外部報酬、評価指定は M1 の責務外。

---

## 完成判定の最終条件 (M1_REDESIGN.md §2.2 から再掲)

X 採用後の評価で 4 基準すべて満たすこと:

- **基準 1 (非破綻性)**: 発火率範囲、silent 比率、爆発なし
- **基準 2 (収束性)**: 訓練後期の同パターン類似度 0.85+
- **基準 3 (識別性)**: 5 パターン (新 A-E) selectivity 0.4+
- **基準 4 (持続性)**: Phase 4 で selectivity 維持

すべて満たせば、M1 プロトタイプは**完成**。
